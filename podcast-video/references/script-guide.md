# 对话稿写法（script.txt）

## 格式

- 每行一个话轮，以 `A: ` 或 `B: ` 开头。A 是主持人小林（晓晓的声音，负责提问、复述和接类比），B 是嘉宾老周（云希的声音，负责讲解）。
- 不以 `A:`/`B:` 开头的行会被忽略，可以用空行分隔段落。
- 声音和语速在 `scripts/make_podcast.py` 的 `VOICES` 里改。

## 篇幅和结构

- 一篇约 4000–5500 字、100–150 行，播客时长约 15–22 分钟。
- 开场：`欢迎收听《节目名》播客，我是小林` → 嘉宾自我介绍 → 一句话点出本期主题，然后马上给一个总体类比。
- 主体：按原文的章节顺序讲，每个知识点走一遍"小林提问 → 老周讲解 → 类比 → 小林用自己的话复述或追问"。
- 收尾：老周一句话总结，小林预告下一期（系列最后一期说系列完结）。

## 类比

- 每个知识点配一个日常生活中人和人交流的场景：早餐店熟客说"老样子"、开会时递小纸条、跟装修师傅约定验收标准、看病前护士先量体温、给钟点工只开部分房间的钥匙。
- 类比要能对上机制，不只是气氛：说清楚"谁对应谁、哪一步对应哪一步"。对比两个相近的概念时，用同一个场景里的两个动作（白板"直接擦掉"和"先拍照写纪要再擦"）。
- 做系列时，各期不要重复用同一个类比。

## 口语化，方便 TTS 朗读

- 符号读出来：`/clear` 写成"斜杠 clear"，`CLAUDE.md` 写成"CLAUDE 点 md"，`--print` 写成"杠杠 print"，`@file` 写成"艾特 file"，`$ARGUMENTS` 写成"美元符号 ARGUMENTS"，`!` 写成"感叹号"。
- 不用 markdown、表格、括号注释、项目符号。列举时用"第一……第二……"。
- 英文术语保留原词（edge-tts 的中文声音能读），但不要整句英文。
- 一句不要太长，超过 120 字就拆成两轮或加一句对方的回应。

## 准确性

- 只讲原文有的内容；版本号、默认值、别名照原文写，没把握的不说。
- 原文标注已废弃或已移除的功能，要明确说"已经不能用了，改用 X"。
